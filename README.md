# Capstone

This project was created for my high school graduation capstone project.

It is a chess gui program that plays against stockfish.

## Tools Used
- Pygame
- Stockfish
- Git
- NeoVim
- Tmux

## Final Thoughts
Overall very happy with the final product. I think that going into it, I had
no idea how complex the project would be and was overabitious with the scope.
However, I think that I learned more because of that.

To begin with my plan was to create a chess engine as well. This ended up being
**way** too large of a project to complete within the deadline. I was able to
learn about the workings of a chess engine and could see it being a future
project.

I also would like to point out the amount of adjecent leaning that happended
alongside this project. I not only got to learn about Python libraries like
Pygame and chess tools like Stockfish but I also got to use many more "workflow"
tools like Git, NeoVim and Tmux.
